# duanju-agent

基于 FastAPI 的短剧与小说创作工作台，包含 `agent/` 后端模块、`static/` 页面，以及 `ai-website-cloner-template/` 中独立的 Next.js 前端。

## 协作开发

- 所有开发者和 Codex 在每次任务前必须阅读 [AGENT.md](AGENT.md)。
- Windows / Mac 首次配置、拉取、提交和推送步骤见 [协作接入说明](docs/COLLABORATION.md)。
- 仓库不包含本机模型密钥、运行语料、知识图谱、作品任务、依赖和缓存；仅提供最小种子语料与配置示例。
- 未经用户明确允许，不启动应用、模拟器、开发服务器或部署服务。

产品与技术背景见 [docs](docs/)；[原始交接说明](交接说明.md) 保留供参考，其中旧部署地址和版本描述不能视为当前运行状态。
