## 1. 项目背景与目标

### 1.1 现状
平台已具备最小闭环（v0.1 demo）：
- 数据采集：红果网页版实时采集（27 部/次，15-25s）
- 知识库：双源语料 39 条（12 手工 + 27 实时），BM25 中文 bigram 检索
- 生成：DashScope qwen-flash 六节点流水线（parse_idea→kb_search→outline→script→scenes→storyboard），SSE 流式
- 展示：Web 三栏工作台（创意输入/生成进度/结果 + 榜单）

### 1.2 本次升级目标（对应需求五大项）
| 模块 | 目标一句话 |
|------|-----------|
| M1 平台类别扩展 | 从"单一红果方向"升级为多维分类体系（创作形式×题材×平台来源×应用场景）+ 类别管理后台 |
| M2 知识图谱 | 建立 剧/钩子/手法/题材 等实体关系图谱，大模型自动抽取，Canvas 力导向可视化 |
| M3 图谱应用 | 灵感索引（多维发现）、剧本生成溯源、关联剧本查询与对比 |
| M4 专项处理 | 短剧特征库、结构模板库、小说→短剧转化引擎、钩子全生命周期管理+智能抽取 |
| M5 质量与性能 | 满足既定量化指标（见 §4） |

### 1.3 目标用户
- 短剧编剧/工作室（核心）：找灵感、拆爆款、生成初稿
- 平台运营：维护类别、审核钩子、看榜单
- AI agent（程序消费方）：通过 API 调用图谱/钩子/语料

## 2. 功能需求（FR）

### M1 平台类别扩展（FR-1）
| 编号 | 需求 | 验收要点 |
|------|------|---------|
| FR-1.1 | 多维度分类体系，≥3 个内容维度 | 维度：①创作形式（真人剧/漫剧/AI剧）②题材类型（逆袭/重生/甜宠/萌宝/玄幻/家庭…）③数据来源平台（红果+预留扩展位）④应用场景（生成参考/钩子素材/结构模板） |
| FR-1.2 | 分类标准、内容特征、数据接口规范成文 | 每类别含 id/name/dimension/features/data_source 字段 |
| FR-1.3 | 类别关联机制，支持交叉引用 | 一条语料可同时挂多维度类别；类别可关联其他类别（如"重生"关联"逆袭"） |
| FR-1.4 | 类别管理后台：动态添加/编辑/归档 | 归档为软删除（archived=true），不参与新语料挂载但历史引用可见 |

### M2 知识图谱可视化（FR-2）
| 编号 | 需求 | 验收要点 |
|------|------|---------|
| FR-2.1 | 图谱数据模型：实体/关系/属性规范 | 实体类型：drama/hook/trope/theme/emotion/style/structure（依据调研报告 §3.4） |
| FR-2.2 | 节点含剧本内容、标准简介、多级标签 | drama 节点含 content_refs（片段+全集关联）、intro（创作背景+主题）、tags（题材/风格/情感三级） |
| FR-2.3 | 大模型知识抽取，含流程与质量标准 | qwen-flash 结构化抽取→置信度评分→<0.6 进审核队列 |
| FR-2.4 | 层级化展示：全局概览+局部细节 | 概览=全图聚类；细节=点节点展开邻域 |
| FR-2.5 | 节点聚类与关系路径高亮 | 按类型/维度着色聚类；选中节点高亮一跳/二跳路径 |
| FR-2.6 | 交互控制 | 缩放 0.1-5.0 倍、平滑拖拽、节点悬停预览（tooltip）、点击查看详情面板 |
| FR-2.7 | 布局算法优化 | 力导向+类型分区初始化，节点不重叠、关系不交叉混乱 |

### M3 图谱功能与应用（FR-3）
| 编号 | 需求 | 验收要点 |
|------|------|---------|
| FR-3.1 | 灵感索引：按主题/情感/结构多维检索 | 三个筛选维度可单独或组合查询 |
| FR-3.2 | 关联推荐：相似或互补内容 | 相似=高关联度；互补=同题材低相似（补差异点） |
| FR-3.3 | 剧本生成溯源：可视化引用节点与路径 | 生成完成后展示"本剧本引用了哪些语料节点+命中字段权重"，可点开来源原文 |
| FR-3.4 | 记录知识应用权重，支持回溯验证 | trace 数据持久化，含每条引用的字段命中明细 |
| FR-3.5 | 关联知识查询：剧本间关联度计算与排序 | 算法=BM25 余弦 0.5 + 标签 Jaccard 0.3 + 钩子重叠 0.2；响应≤300ms |
| FR-3.6 | 相关剧本完整元数据展示 | 名称/作者(来源平台)/采集时间/题材/集数/热度 |
| FR-3.7 | 剧本对比视图：差异高亮+结构比较 | 双栏对照，差异行高亮；结构 beats 并排比较 |

### M4 短剧内容专项处理（FR-4）
| 编号 | 需求 | 验收要点 |
|------|------|---------|
| FR-4.1 | 短剧特征库：爆点/热点/钩子定义与识别规则 | 依据调研报告 §4 规则表实现规则引擎 |
| FR-4.2 | 结构模板库：标准+自定义模板管理 | 内置整剧五段式+单集微闭环；支持创建/编辑/归档 |
| FR-4.3 | 小说→短剧转化引擎：自动抽取+人工标注 | 自动模式=大模型抽取；人工模式=选中文本打标 |
| FR-4.4 | 钩子分类体系与属性标准 | 三属性模型 position/mechanism/intensity |
| FR-4.5 | 钩子创建/编辑/保存/版本管理 | 每次编辑生成版本记录，可查看历史、回滚 |
| FR-4.6 | 钩子与图谱关联，可被 agent 调用 | hook 节点入图谱；生成流水线 kb_search 可召回钩子 |
| FR-4.7 | 大模型钩子智能抽取 | 输入任意剧本文本→输出候选钩子（分类+强度+依据） |
| FR-4.8 | 抽取质量评估+人工审核流程 | 置信度评分；审核队列（待审/通过/驳回） |
| FR-4.9 | 抽取规则自定义与迭代 | 规则可增删改，规则版本记录 |

### M5 系统级（FR-5）
| 编号 | 需求 |
|------|------|
| FR-5.1 | 数据更新频率≤24h：采集时间戳检查，超期自动提示/自动采集 |
| FR-5.2 | ≥2 个扩展接口位：①PlatformAdapter 注册制新平台接入 ②ExportAPI（语料/图谱/钩子导出） |
| FR-5.3 | 核心操作≤3 步：生成（输入创意→点生成→看结果）、采集（点按钮→自动完成）、查图谱（打开图谱页→点节点→看详情） |
| FR-5.4 | 操作指引与错误提示：关键面板内置说明文案；API 错误返回可读中文信息 |

## 3. 非功能需求（NFR）

| 类别 | 指标 | 实现保障 |
|------|------|---------|
| 数据质量 | 图谱数据准确率≥95% | LLM 抽取+置信度过滤+人工审核队列；规则引擎确定性抽取兜底 |
| 数据质量 | 节点关系完整率≥98% | 每条语料入库必经抽取流水线；完整性校验脚本（缺关键字段报警） |
| 界面交互 | 可视化响应≤100ms | Canvas 渲染（非 DOM）、requestAnimationFrame、空间网格加速 |
| 性能 | 并发≥100 | FastAPI 异步 + 语料/图谱全内存检索（单实例内存占用 <200MB） |
| 性能 | 关联查询≤300ms | 预计算邻接表+倒排索引，纯内存计算 |
| 性能 | 数据更新≤24h | 时间戳守护：启动时+每小时检查 corpus_live.json 的 updated |
| 用户体验 | 核心操作≤3步 | 见 FR-5.3 |
| 可扩展性 | ≥2 扩展接口位 | 见 FR-5.2 |
| 兼容性 | Chrome/Edge 现代版本 | 原生 ES2020+，无构建链 |

## 4. 验收标准总表（评审基准）

| # | 验收项 | 通过标准 |
|---|-------|---------|
| A1 | 类别维度数 | ≥4 个维度，每维度 ≥3 个类别 |
| A2 | 类别后台 | 添加/编辑/归档全链路可用 |
| A3 | 图谱规模 | 全量 39 条语料完成抽取，节点 ≥80、关系 ≥120 |
| A4 | 图谱交互 | 缩放/拖拽/悬停/点击/聚类高亮全部可用 |
| A5 | 抽取质量 | 抽样 20 条人工核验，准确率 ≥95%；<0.6 置信度全部进审核队列 |
| A6 | 灵感索引 | 主题/情感/结构三维度检索各返回有效结果 |
| A7 | 溯源 | 一次真实生成产出完整 trace（节点+权重+路径） |
| A8 | 关联查询 | 响应 ≤300ms（P95）；人工抽验排序合理性 |
| A9 | 剧本对比 | 双栏 diff 高亮 + beats 并排 |
| A10 | 钩子管理 | 创建→编辑→版本历史→入图谱→被生成引用 全链路 |
| A11 | 智能抽取 | 输入示例剧本输出 ≥3 个候选钩子且分类正确 |
| A12 | 小说转化 | 输入小说片段输出 ≥2 个短剧元素（钩子/爆点等） |
| A13 | 冒烟测试 | 全部端点自动化检查通过（在原 16 项基础上扩展） |
| A14 | 性能 | 并发 100 路健康检查无错误；关联查询 P95 ≤300ms |

## 5. 范围界定

**本期包含**：上述 FR-1~FR-5 全部功能；单机单实例部署；中文语料。
**本期不包含**：用户账号体系与多租户、分布式部署、移动端 App、视频素材处理、真实付费接口。
**边界依赖**：DashScope API 可用性（LLM 抽取与生成）；红果网页版结构稳定性（采集器含解析失败降级）。

## 6. 风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| LLM 抽取准确率不达标 | 中 | 规则引擎先行（确定性），LLM 仅做补充抽取；置信度门槛+人工审核兜底 |
| 红果页面结构变更 | 中 | 解析失败自动降级保留旧数据；PlatformAdapter 隔离变更影响面 |
| 图谱可视化性能 | 低 | 节点规模受控（<500），Canvas+网格加速，实测验证 |
| 浏览器桥接环境不稳定 | 低 | 全部验证走 HTTP 层冒烟测试（本会话已验证可行） |
