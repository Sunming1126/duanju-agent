# 一键生成反馈与阶段动画

2026-11-03：源码实现，未部署或启动浏览器。

- 小说／剧本的新建与已有作品均使用独立一键提交状态。先显示保存圆环，再提交；新建跳转保持打开提示直到组件卸载。普通保存不触发此动画。已有作品在等待保存前同步加锁，防止重复提交；生成请求仍保留原幂等键与失败不自动重发规则。
- 创建辅助方法追加返回已确认的任务、追加提交前回调。原回调及三参数调用保持兼容，不修改后台协议。作品和已确认任务放入按当前空间与作品编号匹配的内存缓存，60秒失效，身份丢失清除。新页面先展示已保存内容，后台读取确认前禁用编辑，避免手写被初始读取覆盖；重新读取成功后清除交接缓存。不把未确认请求包装成成功任务。
- 路由、身份和作品读取使用保持页头／侧栏的轻量骨架。阶段进度显示真实梗概、人物、大纲、正文状态，以结果记录判定已完成，以completed/total计算进度，未知总量使用不定提示，不虚构百分比或耗时。正文显示章／集编号，排队、停止中、失败与中断分别呈现；失败和停止后停止循环动画，原停止／继续及冲突处理保留。
- 完成提示约3.2秒后收起，有未回填结果或冲突时保持。动画只影响图标、透明度与进度条，不逐字重播正文、不触发滚动或模型请求。prefers-reduced-motion停用旋转／呼吸／滑动／淡入及进度过渡；读屏播报阶段状态，不随每次轮询重新挂载提示。
- 五种界面语言沿用词库及繁体转换，使用逻辑方向间距，阿拉伯语进度条从右侧起始。没有新增前端依赖，当前锁文件依赖补齐后验证。

验证：115项前端回归、lint零警告、TypeScript、webpack生产构建通过。新增覆盖真实进度／停止状态、缓存空间／作品／超时／身份失效、五语言进度与骨架；原创建回归增加保存→提交回调顺序、已确认任务交接和失败不返回任务检查。组件与模拟请求检查不等于浏览器视觉或实际长任务验收。没有实际模型／邮件调用、后端改动、线上部署或应用启动。
