# 中文创作工作台：本机测试

当前前端保留回退后的首页构图和动画，剧本、小说、世界设定和语料参考接入同一个本机后端。只做中文版，不部署服务器。

## 启动

请自己在两个终端启动。需要 Python 3.10+、Node 24+。当前 Mac 已验证可用的 Python 为 `/opt/anaconda3/bin/python`；系统自带 Python 3.9 不适用。

终端一，在项目根目录：

```sh
cd /Users/zhaoqing/myprojects/duanju-agent
DUANJU_SCHEDULER_ENABLED=false DUANJU_WRITER_AUTO_RESUME_ENABLED=false /opt/anaconda3/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8765
```

这两个开关让测试期间不自动采集或续跑以前挂起的编剧任务。它们不改变正式环境的默认行为。缺依赖时使用同一 Python 安装 `requirements.txt`。

终端二：

```sh
cd /Users/zhaoqing/myprojects/duanju-agent/ai-website-cloner-template
npm run dev -- --webpack --hostname 127.0.0.1 --port 3000
```

然后自行打开 [本机首页](http://127.0.0.1:3000)。后端默认 `127.0.0.1:8765`；如需改地址，参考前端 `.env.example` 设置 `DUANJU_BACKEND_URL` 并重启前端。没有 `NEXT_PUBLIC` 密钥配置。

已按用户提供的地址配置 `deepseek-v4.1-flash`，密钥仅存于被 Git 忽略的 `data/llm_config.json`。新电脑需要重新配置，不能从 GitHub 同步密钥。前端“模型设置”可更换配置，留空保留已有值，保存不会自动调用模型。

## 验收路径

1. 首页点“剧本创作”或“小说创作”，填写名称、题材、数量、故事想法，点击“创建并 AI 生成”：先保存作品，再启动故事设定生成。也可选择“仅创建草稿”，稍后再生成，或导入 TXT 作为创作素材。
2. 在“世界设定”新建世界，分别填写规则、自然地理、人文社会、人物关系、历史事实、故事伏笔并保存。世界独立于作品，可给多个作品绑定。
3. 在作品中选择世界并保存。分步骤编辑故事设定、人物小传、大纲；在正文中选择具体集／章。
4. 在对应步骤点“AI 生成故事设定／人物小传／大纲／正文”；有未保存修改时会先保存，保存失败不会发起模型请求。空候选区也提供生成按钮。候选先独立保存，只有“确认采纳”才写入作品。作品或世界版本已变时会拒绝采纳旧候选，文本仍可导出。失败明确显示，不用模板冒充真实生成结果。
5. 保存后返回列表、搜索、按剧本／小说筛选，再打开检查恢复。导出 TXT 包含当前编辑内容。出现版本冲突，可先导出，再点“重新加载”。
6. 世界可导出与导入本工作台自己的 JSON 草稿包，带完整性校验；导入创建新世界，不覆盖原稿。不支持直接导入 StoryForge 完整备份。
7. “语料参考”读取现有语料平台的中文记录，支持按类型与关键词检索、查看来源、带参考创建作品。无对应语料时显示空状态，不伪造数据。
8. 如原浏览器有旧版草稿，点击“导入旧草稿”。重复导入不会覆盖新作品，原 localStorage 不删除。旧“正文”原先是单一文本，因此迁移为第 1 集，其余原样保留。

## 数据与实现边界

- 新工作台保存于 `data/studio/studio.sqlite3`，可通过 `DUANJU_STUDIO_DB` 指定测试文件。后端重启保留已保存稿件，生成中断的任务标记失败，不自动重复付费请求。尚未保存的编辑内容仍需手动保存或导出。
- 复用原平台的模型客户端、中国市场语料检索、中文短剧规则。小说采用独立的中文小说叙事提示。当前未接入原多阶段编剧任务、自动质量修订或批量全书生成，不宣称完整移植 StoryForge。
- 世界的模块分类与规范化算法来源见 `third_party/storyforge/README.md`。本轮为基础文本编辑与冻结引用，没有地图和游戏等扩展。
- 新接口在 `/api/studio/*`；前端通过同源 `/api/backend/*` 代理。显式发送中国市场标记；现有日本站接口维持隔离。
- 生成采用已保存作品与世界的快照，包含前文和当前单元。超过上下文容量会明确失败，不悄悄截去世界规则。长篇需精简背景、分章手动生成；200 个单元是编辑容量，不代表单次生成可可靠覆盖 200 章。
- 目前是单机测试用途，没有新增登录、会员、远程部署或多人权限系统。
