## 一、短剧与小说的本质差异分析

### 1.1 八维差异总表

| 维度       | 小说             | 短剧（竖屏微短剧）                  |
| -------- | -------------- | -------------------------- |
| **媒介形态** | 纯文字，靠想象补全      | 视听语言，画面/台词/表演直接呈现          |
| **消费场景** | 沉浸式长阅读，可随时暂停回看 | 通勤/排队等碎片时间，单集 1-3 分钟，随时划走  |
| **竞争对象** | 同类小说           | 全部短视频（抖音/快手信息流），前 3 秒定生死   |
| **节奏容错** | 铺垫可长达数千字       | 黄金 3 秒无冲突即流失，前 3 集定留存      |
| **情绪密度** | 每 1-2 章一个情绪点   | 每集必须有情绪点，理想 30-60 秒一个小刺激   |
| **变现机制** | 章节订阅 / 免费+广告   | 第 8-12 集卡点付费、广告解锁、IAA 内购混合 |
| **结构单元** | 章 = 情节推进单元     | 集 = 完整微闭环（钩子→冲突→反转→下集钩）    |
| **人物容量** | 可承载复杂群像与心理描写   | 主角 + 强对立反派 + 少量功能配角，极简     |

### 1.2 五条本质结论（指导系统设计）

1. **注意力经济压倒叙事完整性**：短剧每一秒都在与"划走"对抗。→ 系统需将"钩子/爆点"作为一等公民建模，而非普通文本属性。
2. **外化表达**：小说可写内心独白，短剧必须转化为可见动作/台词/表情。→ 转化引擎的核心任务：心理描写 → 动作 + 台词。
3. **集级微闭环**：单集是独立的情绪产品，同时承担整剧叙事推进。→ 结构模板库以"集"为单位设计 beats。
4. **付费卡点是叙事节点**：卡点集必须停在最强悬念上。→ 语料结构中 `pay_card` 字段独立建模。
5. **口语化台词驱动**：短剧对白占比 60% 以上，单句 ≤15 字。→ 生成 agent 的剧本节点需遵循此约束（已在 demo 流水线 prompt 中体现）。

### 1.3 转化映射关系（小说 → 短剧）

| 小说元素 | 短剧转化目标             | 转化手法     |
| ---- | ------------------ | -------- |
| 环境描写 | 空镜/字幕卡/一句台词交代      | 压缩为 ≤2 句 |
| 内心活动 | 面部特写 + 独白旁白 + 动作外化 | 视觉化      |
| 多线叙事 | 主线单线程 + 极简插叙       | 降维       |
| 长铺垫  | 删除，直接从冲突切入         | 倒叙钩子开场   |
| 心理博弈 | 台词交锋 + 动作性反击       | 对白化      |
| 章末悬念 | 集尾钩（更强的悬念/反转预告）    | 强化       |

## 二、短剧创作手法分类与应用场景

### 2.1 六大类创作手法

**A. 节奏控制类**

| 手法    | 定义                  | 应用场景              |
| ----- | ------------------- | ----------------- |
| 黄金三秒  | 开场 3 秒内出现冲突/悬念/视觉奇观 | 每集开头，尤其第 1 集      |
| 卡点    | 在情绪/悬念峰值处切断（集尾或付费点） | 每集结尾、第 8-12 集付费卡点 |
| 快切场景  | 单场景时长 ≤40 秒，快速换场    | 中段爽点循环期           |
| 倒计时压迫 | 制造时间deadline增强紧张感   | 高潮集、营救/比赛情节       |

**B. 情绪设计类**

| 手法    | 定义                   | 应用场景         |
| ----- | -------------------- | ------------ |
| 爽点    | 压抑→释放的情绪回报（打脸、揭露、复仇） | 每 1-2 集一个主爽点 |
| 虐点    | 委屈/牺牲/背叛引发的情绪卷入      | 爽点前的蓄力段      |
| 甜点    | 情感互动的甜蜜瞬间            | 甜宠题材节奏调剂     |
| 情绪过山车 | 虐→爽交替编排              | 整剧节奏骨架       |

**C. 悬念钩子类**（详见第四章钩子定义）

| 手法  | 定义               | 应用场景        |
| --- | ---------------- | ----------- |
| 开场钩 | 3 秒内抛出反常画面/台词    | 全部集数        |
| 信息差 | 观众知道、角色不知道（或反之）  | 马甲文、复仇文核心引擎 |
| 结尾钩 | 集尾抛出新的危机/悬念/反转预告 | 每集最后 10 秒   |

**D. 反转设计类**

| 手法   | 定义             | 案例              |
| ---- | -------------- | --------------- |
| 身份反转 | 废柴/底层身份揭秘为隐藏大佬 | 《无双》：上门女婿实为战神龙王 |
| 立场反转 | 盟友变敌人/敌人变盟友    | 权谋剧中段常见         |
| 认知反转 | 打破观众既有判断       | 悬疑线             |
| 局势反转 | 绝境中翻盘          | 每个爽点单元的收束       |

**E. 人设模板类**

| 手法    | 典型设定          | 语料案例                           |
| ----- | ------------- | ------------------------------ |
| 废柴逆袭  | 被轻视→觉醒→碾压     | 《无双》《废物垫底皇子，反倒成为千古一帝》          |
| 重生复仇  | 带记忆重开人生       | 《重生！丑小鸭逆袭成了万人迷第二季》《重生之我在豪门搞科研》 |
| 马甲大佬  | 多重隐藏身份逐一揭露    | 《无双》                           |
| 系统金手指 | 绑定系统/异能获得成长加速 | 《我都元婴期了，你跟我说开学》                |
| 甜宠错位  | 身份错位/契约关系产生情感 | 《闪婚老伴是豪门》《我在八零年代当后妈》           |
| 萌宝牵线  | 萌娃推动主线        | 《糯糯下山，师兄们都慌了第三季》               |

**F. 题材组合类**

* 交汇公式：`基础题材 × 热门元素 × 情感基调`，如"古装 × 重生 × 复仇"（《长公主在上》）、"都市 × 穿越 × 玄幻"（《我都元婴期了，你跟我说开学》）。

* 应用：灵感索引系统的"题材组合发现"直接复用此公式。

### 2.2 手法应用场景速查（按剧情阶段）

| 阶段    | 集数       | 主力手法                 |
| ----- | -------- | -------------------- |
| 开局定生死 | 1-3 集    | 黄金三秒、人设速立、核心冲突抛出、开场钩 |
| 爽点循环  | 4-12 集   | 受辱→蓄力→打脸循环、信息差、结尾钩   |
| 付费转化  | 8-12 集卡点 | 最强悬念切断、重大反转预告        |
| 升级扩展  | 13-40 集  | 新地图/新敌人、身份逐层揭露       |
| 高潮收束  | 倒数 3-5 集 | 终极打脸、所有伏笔回收、情感高潮     |

## 三、短剧结构要素与通用格式规范

### 3.1 整剧结构（以 80-100 集为例）

```
[开局 1-3集] 人设+世界观+核心冲突，第1集结束前完成"受辱事件"
    ↓
[第一爽点循环 4-12集] 小循环×3：受辱铺垫→蓄力→第一次打脸
    ↓ ★ 卡点集(8-12)：在最大悬念处切，推动付费
[升级段 13-40集] 新势力入场，身份揭露第一层，爽点规模升级
    ↓
[中段 41-70集] 感情线与主线交织，虐点蓄力，大反派浮出水面
    ↓
[高潮 71-95集] 终极危机→绝境→终极反转→终极打脸
    ↓
[结局 96-100集] 伏笔全回收，情感收束（HE/BE），下季钩（可选）
```

### 3.2 单集微闭环结构（120 秒标准）

| 时段       | 功能   | 要素                   |
| -------- | ---- | -------------------- |
| 0-3s     | 开场钩  | 反常画面 / 冲突台词 / 上集悬念重击 |
| 3-30s    | 冲突建立 | 本集矛盾主体登场，目标清晰        |
| 30-90s   | 情绪推进 | 1-2 次小反转，情绪逐步拉满      |
| 90-110s  | 集内爆点 | 本集爽点/虐点兑现            |
| 110-120s | 结尾钩  | 新悬念/危机/反转预告，切断       |

参考语料（手工结构化）单集 beats 示例（《无双》第 1 集）：
`["受辱铺垫(0-30s)", "身份悬念(30-60s)", "第一次打脸(60-90s)", "更大危机压顶(90-120s)"]`

### 3.3 剧本格式规范

**场（Scene）**

```
场次编号 | 场景（内/外景-地点-时间） | 出场人物
动作描述：现在时态、只写可拍摄内容，每段 ≤3 行
台词：角色名 + 台词，单句 ≤15 字，口语化
（可选）分镜标注：景别（特写/近景/中景/全景）+ 镜头运动
```

**约束清单（生成 agent 必须遵守）**

1. 每集 2-4 个场次（竖屏短剧标准）
2. 动作描述不写心理活动，只写可见行为
3. 台词口语化，禁止长篇独白（单次 ≤3 句）
4. 每集必须含：1 个开场钩 + 1 个集内爆点 + 1 个结尾钩
5. 反派台词允许"作死式嚣张"，为打脸蓄力

### 3.4 结构要素总表（知识图谱建模依据）

| 要素       | 层级  | 图谱实体类型                  |
| -------- | --- | ----------------------- |
| 整剧       | 剧集级 | drama                   |
| 幕/段落     | 剧集级 | structure(beat)         |
| 集        | 集级  | structure(beat)         |
| 场        | 场级  | —（剧本内部）                 |
| 钩子       | 元素级 | hook                    |
| 爆点/爽点    | 元素级 | hook(子类 peak)           |
| 反转       | 元素级 | trope                   |
| 人设模板     | 元素级 | trope                   |
| 题材/情感/风格 | 标签级 | theme / emotion / style |

## 四、核心元素定义与案例库

### 4.1 钩子（Hook）

**定义**：在注意力决策点（开场/转场/集尾）制造的、以"阻止划走 + 建立期待"为目标的叙事装置。

**三属性模型**（钩子管理的属性标准）：

* `position` 位置：open(开场) / mid(转场) / tail(集尾)

* `mechanism` 机制：悬念 / 危机 / 反差 / 期待承诺

* `intensity` 强度：1-5（5 = 强制追更级）

**分类体系与识别规则**：

| 类型  | 定义        | 识别规则（规则引擎用）                |
| --- | --------- | -------------------------- |
| 悬念钩 | 抛出未解之谜    | 含"是谁/为什么/秘密/隐藏/竟然"且无即时解答   |
| 危机钩 | 主角陷入即时危险  | 含"死/杀/毁/倒数/最后"等高危词 + 主角受威胁 |
| 反差钩 | 强烈对比画面    | 身份词冲突（废物/龙王、保姆/总裁同现）       |
| 期待钩 | 预告即将发生的爽点 | 含"下一集/接下来/等着/我会让你"         |
| 金句钩 | 高共鸣台词收尾   | 疑问句/宣言句结尾 + 情绪词            |

**案例库（来自本平台语料）**：

1. 《无双》开场钩（反差+悬念）：`"三年之期已到，恭迎龙王回归"` —— 上门女婿身份与"龙王"称谓强反差。
2. 《无双》金句钩：`"你叫我一声废物，我还你一个天下"` —— 宣言句+情绪词，强度 5。
3. 《我都元婴期了，你跟我说开学》标题即钩（反差）：修仙大能 × 开学日常，标题自带信息差。
4. 《糯糯下山，师兄们都慌了第三季》期待钩（采集语料 logline）：六岁萌娃下山寻兄，五位师兄身份逐一揭露——期待钩串联整季。
5. 《重生之我在豪门搞科研》开场钩（危机+反差）：重生回到被退婚当日，带着科研系统反杀。

### 4.2 爆点（Peak）

**定义**：情绪强度的局部峰值时刻，是"压抑→释放"结构的释放点。
**与钩子的区别**：钩子制造期待（向前拉注意力），爆点兑现期待（情绪满足）。
**识别规则**：打脸动作完成瞬间 / 身份揭露瞬间 / 反派伏法瞬间 / 真相大白瞬间。
**密度标准**：每集 ≥1 个，每 3 集 1 个大爆点。

### 4.3 热点（Trend）

**定义**：对社会话题、流行梗、节令事件的借用，用于提升话题传播度与算法推荐友好度。
**类型**：话题热点（赘婿/裁员/彩礼）、梗热点（网络流行语）、节令热点（春节团圆/高考）。
**应用规则**：热点必须服务主线，不得硬贴；热点元素在剧名或前 3 集露出效果最佳。

### 4.4 爽点（Payoff）

**定义**：观众代入主角后，被压抑情绪获得回报的设计单元。标准四拍：受辱铺垫 → 蓄力（隐藏优势展示给观众）→ 反击 → 结果碾压。
**与爆点关系**：爽点是结构单元（四拍全程），爆点是爽点第四拍的情绪峰值瞬间。

### 4.5 卡点（Paywall Point）

**定义**：付费墙设置位置及其配套叙事设计。
**选点标准**：多重危机叠加 + 最大信息差即将揭晓处；一般在第 8-12 集。
**设计要求**：卡点前 3 集持续升温，卡点集结尾 = 全剧至最强钩。

### 4.6 元素关系图（图谱建模依据）

```
钩子(Hook) --制造期待--> 爆点(Peak) --归属--> 爽点(Payoff)
                                    爽点 --循环编排--> 卡点(Paywall)
热点(Trend) --嫁接--> 任意元素（题材级增强）
```

## 六、对后续模块的理论约束摘要

1. 图谱实体类型必须采用 3.4 节总表命名（drama/hook/trope/theme/emotion/style/structure）。
2. 钩子管理系统的属性模型必须实现 4.1 三属性（position/mechanism/intensity）。
3. 智能抽取的识别规则以 4.1/4.2 规则表为 v1 基线，允许迭代但需记录版本。
