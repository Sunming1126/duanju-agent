## 本机访问

本次已建立临时 SSH 隧道，访问 http://127.0.0.1:18765 。电脑重启或隧道中断后，在终端运行：

```sh
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:18765:127.0.0.1:8765 onesay-server
```

保持终端打开，再访问上述地址。若提示本地端口已占用，先检查是否已有隧道。
本次后台隧道可单独关闭：

```sh
ssh -S /tmp/duanju-agent-ssh-18765.sock -O exit onesay-server
```

## 仅管理本项目

```sh
ssh onesay-server 'systemctl status duanju-agent --no-pager'
ssh onesay-server 'sudo journalctl -u duanju-agent -n 50 --no-pager'
ssh onesay-server 'sudo systemctl restart duanju-agent'
```

需要停用时，仅执行 `sudo systemctl disable --now duanju-agent`，保留数据目录；不要使用 PM2 全量重启或 Docker 全局清理命令。
更新代码前先备份本项目 data，避免用本地旧数据覆盖服务器作品。
