## 视觉和交互约定

截图为高分辨率画面，按约 1160px CSS 宽的桌面画布校准比例：黑色细斜纹背景，深灰面板，左上名称，左侧紧凑四格导航，当前项白底，右侧渐变操作。设置页为两列表单和右侧竖向目录；人物页左侧大面板、右侧小方卡；大纲页右侧为四张结构卡；正文空状态保留大片留白。小屏使用单列表单、顶部横向角色卡和结构卡，截图没有提供的移动端布局为适配推断。

- 题材／核心／风格可选择或输入自定义标签，分别限制 3／3／5 项。
- 可以添加、选择、编辑与确认删除角色；撤销可恢复本轮删除。
- 可以折叠粗纲、切换起承转合并添加集纲，创建新集和编辑正文。
- 支持本轮撤销／重做；刷新后从独立 `plotloom-reference-preview-v1:<id>` 浏览器草稿恢复内容。不同预览 id 互不覆盖，既有作品草稿键保持不变。
- 正文导出使用 Word 可打开的 HTML `.doc` 文件，并非原生 `.docx`；导出前转义用户内容。空正文给出提示。
- AI、灵感、对白翻译仅展示未接入说明，不生成假结果，不显示原站截图中的 50／80 积分价格。
- 默认仅开发环境可访问；生产环境需显式设置 `PLOTLOOM_ENABLE_REFERENCE_PREVIEW=1` 才开放。
