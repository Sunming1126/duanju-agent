# StoryPlay 前端复刻记录

参考页面：https://storyplay.cn/
记录日期：2026-10-22

## 本次范围

用户要求先做本地前端，不部署，启动与交互调试由用户操作。
- 复刻公开首页的黑色视觉、文字层级、首屏、倾斜海报墙、短剧拉片区、平台标志和评价区。
- 首页的「剧本评估」「灵感策划」「剧本创作」三个标题后面的产品介绍、展示大图及轮播全部省略，只保留紧凑入口。
- 不做登录、注册、会员、充值、邀请、客服、企业 API 等次要功能。
- 按用户要求跳过登录。主要按钮接到本地交互原型，不调用原站接口。

## 页面与路由

| 原站/入口 | 本地路由 | 实现范围 |
| --- | --- | --- |
| https://storyplay.cn/ | `/` | 公开首页的有范围复刻 |
| 立即体验、创作工作台 | `/workspace` | 本地作品列表、搜索及分类 |
| 新建剧本 | `/workspace?create=new` | 创建表单、作品编辑 |
| 小说改编 | `/workspace?create=adapt` | 录入小说素材，建立改编草稿 |
| 剧本改写 | `/workspace?create=rewrite` | 录入已有剧本，建立改写草稿 |
| 灵感策划 | `/workspace?create=inspiration` | 录入故事想法，建立草稿 |
| 剧本评估 | `/workspace?tool=evaluate` | TXT 导入、粘贴内容、字数统计；不产生评分 |
| 查看更多拉片、海报点击 | `/lapian`、`/lapian?detail=编号` | 海报列表、搜索、题材/标记筛选、详情弹窗 |
| 使用教程 | 原站公开飞书链接 | 保留外部链接，点击新窗口打开 |

除首页外，以上本地路由由本次前端实现定义，并非声称与原站登录后路由一致。

## 观察依据

通过原站浏览器页面检查了 1280 × 720 的公开首页、首屏及拉片区、主要入口触发的登录窗口，以及页面公开 DOM 和 CSS 声明。
- 原站背景为黑色，字体为系统字体栈，中文包括 PingFang SC / Microsoft YaHei。
- 首屏标题 46px、前导标题 16px 青色、正文 16px；主按钮为白色圆角。
- 拉片标题 32px 金色，海报按 5 列 × 2 行排列，每列约 220px，海报有真实「新」「爆」角标。
- 海报墙为滚动驱动的倾斜与缩放变化。本版用滚动进度在倾斜态和正视网格态之间插值，不用点击模拟滚动。
- 原站公开首页具有固定的最小宽度 1204px。本版另做移动端适配，不把这部分称为原站手机端的精确复刻。
- 原站「立即体验」「查看更多拉片」在未登录状态均弹出登录窗口；未登录、注册或向原站提交表单，未访问私有工作区。
- 登录后的工作台、创建和编辑页面不可见，因此本版这些页面是延续首页视觉的交互原型，不声称还原了原站私有界面。

## 图片素材

`assets.json` 记录 31 个公开素材的来源 URL、本地文件、Content-Type 和下载字节数。
图片位于 `public/sites/storyplay/`；已检查实际文件类型及海报尺寸，并逐张查看了 10 张海报以转录剧名。
原站海报及标志仅用作此次本地界面参考，未复制原站 JS 作为应用代码。
题材分类由本地预览定义；没有伪造播放量、热度、分集拆解或 AI 评分。

## 代码归属

- `src/components/sites/storyplay/home.tsx`：首页。
- `src/components/sites/storyplay/library.tsx`：拉片交互原型。
- `src/components/sites/storyplay/workspace.tsx`：作品管理、创建、编辑、导入和导出。
- `src/components/sites/storyplay/shared.tsx`：标志、导航、原生 dialog、标题装饰。
- `src/components/sites/storyplay/data.ts`：海报资料与本地草稿结构校验。
- `src/app/globals.css`：独立模板应用的样式、响应式和减少动态效果设置。

## 数据与功能边界

作品保存在当前浏览器的 localStorage（`storyplay-local-projects-v1`），不同浏览器/设备之间不共享。清理浏览器数据会删除草稿，因此建议导出 TXT 留存。
创建作品、搜索分类、编辑故事设定/人物/大纲/正文、显式保存草稿和 TXT 导出均已实现前端逻辑。
AI 辅助创作、小说自动改编、自动改写、评估和剧本拆解未接入；界面显示其状态，不产生虚构结果。
无身份认证、会员、付费流程、部署或对父目录短剧项目的接口接入。
